# Supply Chain Knowledge Graph + MCP

Ask questions about a supply chain in plain English and get answers straight from a Neo4j graph database, through Claude. No queries to write: Claude reads the graph's structure, picks an analysis tool or writes the Cypher itself, runs it, and explains the result.

```
You ──question──> Claude Desktop ──MCP (stdio)──> server.py ──Cypher, read-only──> Neo4j graph
                         <──────────── answer built from the query results ────────────
```

**Example questions**
- Which parts are single-sourced, and which products would stop if that supplier failed?
- If supplier SUP007 shut down tomorrow, how much revenue is at risk?
- Which carrier has the worst on-time delivery rate, and is it getting worse?
- Which warehouses are below their reorder point, and which plant can resupply them fastest?
- How exposed are we to the Taiwan typhoon? Which products, and are any parts single-sourced?
- Show the full supply map for the Robot Vacuum, including tier-2 suppliers.
- Which customers in the Southwest had the most late deliveries last quarter?

## What's in the graph

12 node types and 16 relationship types modeling a multi-tier supply chain, from raw materials to the customer:

```
(Supplier tier 2)-[:SUPPLIES_TO]->(Supplier tier 1)-[:SUPPLIES]->(Part)<-[:HAS_COMPONENT]-(Product)
(Plant)-[:PRODUCES]->(Product)        (Plant)-[:SHIPS_TO]->(Warehouse)-[:STOCKS]->(Product)
(Customer)-[:PLACED]->(SalesOrder)-[:CONTAINS]->(Product)
(SalesOrder)-[:FULFILLED_BY]->(Shipment)-[:SHIPPED_FROM]->(Warehouse)    (Shipment)-[:CARRIED_BY]->(Carrier)
(Plant)-[:ISSUED]->(PurchaseOrder)-[:ORDERED_FROM]->(Supplier)           (PurchaseOrder)-[:FOR_PART]->(Part)
(Supplier|Plant|Warehouse)-[:LOCATED_IN]->(Country)<-[:AFFECTS]-(RiskEvent)-[:AFFECTS]->(Supplier)
```

The included dataset is **synthetic** (generated by `generate_data.py` with a fixed seed): 40 suppliers in 12 countries, 52 parts, 15 products, 4 plants, 6 distribution centers, 6 carriers, 50 customers, 600 sales orders and shipments, 400 purchase orders, and 5 risk events. About 1,800 nodes and 5,100 relationships. It has realistic problems built in for the questions above: single-sourced parts, an unreliable carrier, low stock at some warehouses, and risk events in supplier countries.

## MCP tools Claude gets

| Tool | What it answers |
|---|---|
| `get_graph_schema` | Labels, relationship patterns, properties, and counts (works on any graph) |
| `run_cypher_query` | Any read-only Cypher query Claude writes (works on any graph) |
| `find_single_source_parts` | Single points of failure in the supply base |
| `supplier_disruption_impact` | Parts, products, and 90-day revenue at risk if a supplier fails (tier 1 or tier 2) |
| `late_shipment_analysis` | Late rate and average days late by carrier, warehouse, or customer region |
| `inventory_below_reorder_point` | Stock shortfalls and the fastest plant to resupply |
| `risk_event_exposure` | Suppliers, parts, and products exposed to each risk event |
| `trace_product_supply` | Full upstream map of one product: plants, parts, suppliers, tier 2, countries |

**Read-only by design.** Every query runs in a Neo4j READ transaction, and queries containing CREATE, MERGE, SET, DELETE, REMOVE, DROP, or LOAD CSV are rejected before they reach the database. Claude can never change your data.

## Setup (Windows, about 20 minutes, once)

You need Python 3.10 or newer and the Claude Desktop app.

**1. Get a Neo4j database (free).** Easiest is Neo4j AuraDB Free: sign up at https://console.neo4j.io, create a Free instance, and download the credentials file it shows you once. It contains the URI, username, and password. (Alternatively install Neo4j Desktop and create a local database; then the URI is `neo4j://localhost:7687`.)

**2. Install the project.** Open PowerShell in this folder:
```
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env
```
Paste your URI, username, and password into `.env` and save.

**3. Load the graph.**
```
python generate_data.py
python load_graph.py
python smoke_test.py
```
`load_graph.py` should end with about 1,790 nodes and 5,085 relationships. `smoke_test.py` should print PASS on every line.

**4. Connect Claude.** In Claude Desktop open Settings, then Developer, then Edit Config. This opens `claude_desktop_config.json`. Copy in the block from `claude_desktop_config.example.json`, replacing both paths with the real full paths to this folder's `.venv\Scripts\python.exe` and `server.py` (use double backslashes). Save and fully quit and reopen Claude Desktop.

**5. Ask.** In a new chat, ask "What does my supply chain graph contain?" Claude should call `get_graph_schema`. Then try the example questions.

## Using your own supply chain data

`load_graph.py` loads any data in this simple CSV format, so you can model a different supply chain problem without touching the code:

- `my_data/nodes/<Label>.csv`: an `id` column plus any property columns. One file per node type, e.g. `Supplier.csv`.
- `my_data/rels/<TYPE>.csv`: columns `from_label, from_id, to_label, to_id` plus any property columns, e.g. `SUPPLIES.csv`.

Numbers load as numbers, `true`/`false` as booleans, and columns ending in `_date` (YYYY-MM-DD) as dates. Then run `python load_graph.py --data my_data --reset`.

Claude can answer questions about any data through `get_graph_schema` and `run_cypher_query`. The six analysis tools need the labels and relationships shown above; if your data uses different names, they say so and Claude falls back to writing Cypher.

## Files

| File | Purpose |
|---|---|
| `generate_data.py` | Builds the synthetic dataset in `data/` |
| `load_graph.py` | Loads any nodes/rels CSV folder into Neo4j with unique-id constraints and batched writes |
| `server.py` | The MCP server (Python MCP SDK, FastMCP) with the eight tools |
| `config.py` | Reads the Neo4j connection from `.env` |
| `smoke_test.py` | Checks the database connection and every tool before you use Claude |

## Troubleshooting

- **Claude does not show the tools:** the paths in the config are wrong or Claude Desktop was not fully restarted. Check Settings, then Developer, for the server's status and log.
- **"Cannot reach Neo4j":** the database is stopped (AuraDB Free pauses after a period of inactivity; resume it in the console) or the URI in `.env` is wrong.
- **"Neo4j rejected the username or password":** fix `.env`.
